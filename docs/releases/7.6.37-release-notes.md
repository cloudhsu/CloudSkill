# CloudBox Skills 7.6.37 release

Covers PRs #34–79, a two-day continuous session (2026-08-22 to 2026-08-23).
Full detail in `CHANGELOG.md`'s 7.6.37 entry; this is the short version.

## Summary

Four real workstreams landed together:

1. **Runtime-execution analysis tooling** — Bayesian confidence intervals,
   a pessimistic priority ranker, a Wright's-Law learning-curve tracker, and
   an ablation-study runner, all built against a new committed execution
   ledger of real (not simulated) outcomes.
2. **A real defect found and closed** — a router "feels trivial" trap and a
   cross-Skill fabricated-identity leak, discovered via the ablation runs
   above, closed with a deterministic scan+redact mechanism after two
   content-only fixes were defeated.
3. **Eval Inbox batch review** — roughly 20 candidates converted into real
   Skill content across game/architecture/governance Skills, one found
   redundant and archived without change.
4. **A new optional Skill-bundled hook mechanism**, with 7 real hooks
   shipped and tested against multiple real scenarios each — deterministic
   enforcement (draft-catalog pairing, identity-leak backstop, paired-test
   discipline) and advisory reminders (lifecycle evidence, HTML-view sync,
   mandatory tracker-sync) across all 3 supported coding-agent providers.

## Validation evidence

- `python3 scripts/run_all_checks.py`: PASS at the release tip.
- Every hook shipped this cycle was tested against multiple real positive/
  negative/edge scenarios before merge, not just written and assumed
  correct (see each hook's own manifest description for its scenario list).
- Both Gemini and Codex plugin projections re-synced and verified in parity
  with the canonical `.agents/skills/` source.

## Limits — what this release does NOT claim

- Real behavior-depth execution evidence still covers only 10/40 Skills
  (25%); the other 30/40 have routing-level real evidence only. This
  release adds Skill content and eval case *contracts* faster than it adds
  real execution against those contracts — the gap did not close this
  cycle, and by case count it widened slightly.
- The deterministic rubric grader (`grade_behavior_evals.py`) is verified
  correct on its own narrow self-test, but covers only 7 of 303 behavior
  cases and targets a different (local-model) pipeline than the one that
  produced this cycle's real execution-ledger entries; those entries were
  graded by direct model judgment, not an independent deterministic or
  cross-checked mechanism.
- No hardware, device, platform-install, or production-deployment claims
  are made by anything in this release; all evidence is repository-level
  (`run_all_checks.py`, hook scenario tests, real CLI execution against the
  documented eval cases).
