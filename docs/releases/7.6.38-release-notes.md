# CloudBox Skills 7.6.38 release

Covers PRs #80–90. Full detail in `CHANGELOG.md`'s 7.6.38 entry.

## Summary

- 2 new advisory hooks (`release-cut-reminder`, `shared-checkout-guard`),
  each a direct response to a real gap hit this session.
- A session self-audit converted 4 real mistakes (a shell-quoting bug, a
  wrong-guessed PR branch name, a cross-fork case-ID collision, a
  candidate-capture-status misreport) into skill content and a new hook.
- `coding-agent-project-governance` split: git-mechanics content and 4
  hooks moved into a new skill, `coding-agent-git-discipline`, reached
  through a real architecture discussion that rejected a "shared
  governance core" in favor of domain-specific risk taxonomies.
- A real bug in `scripts/export_public_bundle.py` (CSV comma-quoting)
  found by actually running the export, not by the standard check suite.
- `docs/CLOUDBOX_SKILLS_DEVELOPMENT_MAP.md` refreshed after 90+ commits of
  drift; `docs/index.html` added as a local human-readable registry view.

## Validation evidence

- `python3 scripts/run_all_checks.py`: PASS at the release tip.
- `python3 scripts/export_public_bundle.py --dest <scratch>`: PASS (exit
  0) on a real dry run -- new skill correctly included, private-tier
  skills correctly excluded. This is the first time this cycle the public
  export path was actually exercised, not assumed.
- Both `record-push-outcome`/`block-push-auth-loop` (moved) and the 2 new
  hooks were smoke-tested at their post-move installed paths across all 4
  consumer repos (cloudbox-skills, lotto, cloudbox-engine, WphApp) before
  the old paths were removed.

## Limits

- Real behavior-depth execution evidence is still 10/41 skills (24%); this
  release's own new content (routing/behavior cases for
  `coding-agent-git-discipline`, the self-audit cases) has zero real
  execution yet -- structural/contract validation only.
- `coding-agent-git-discipline` is `experimental` stage with zero real
  execution evidence, though its `core` (public) distribution tier is
  intentional and has precedent (`about-me`, `teach-while-building` are
  also experimental+core).
- No hardware, device, platform-install, or production-deployment claims.
