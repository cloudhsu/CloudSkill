The release contains composable lifecycle templates, type-preserving evidence
identity, layer-typed RED/GREEN governance, and version/schema/runtime-bound
manual Eval exchange. Genuine 6.3 path provenance is removed before persistence
and routed to manual review; incomplete import rollback becomes a durable
reconciliation state rather than a false success.

Rollback uses immutable `v6.3.0`. Bundle/exporter format remains 2.0 and
candidate schema remains 1.0.

## Validation pause

After 6.4.0, proactive Skill evolution pauses while CloudBox is exercised on
real software projects. Project evidence and exported Eval candidates may be
collected, but formal Skill changes require later explicit batch-review
instruction or a blocking safety/correctness defect. This pause does not block
ordinary use, manual import, compatibility fixes, or evidence capture.
