## Remaining limitation

Behavior execution was re-run against each candidate's own staged wording
during the eval-loop comparisons, not against the final committed
`SKILL.md`/reference text after promotion. Re-running the same comparison
scenarios against the merged reference-file text is a `MANUAL_REQUIRED`
follow-up, consistent with `developing-skills`' own rule that structural
validation is not a behavior pass.

## Local Claude Code plugin cache

Updating the CACHED plugin content that Claude Code actually loads still
requires, on the machine used for editing:

```
claude plugin marketplace update <marketplace-name>
claude plugin update cloudbox@<marketplace-name> --scope user
```

followed by a session restart/reload — the underlying git checkout being
current does not by itself update `~/.claude/plugins/cache/...`.
