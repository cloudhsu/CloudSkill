- `.agents/skills/wph-equipment-simulator-development/lifecycle.json`:
  `stage` `experimental` -> `active`; `next_review_triggers` updated to
  reflect the still-open tier confirmation and the not-yet-authored numeric

- Version bump `7.6.28` -> `7.6.29`. **Classification note**: this was
  first attempted as a **minor** bump (`7.7.0`), reasoning that reaching
  `active` is a new capability commitment. That attempt was reverted after
  it surfaced a real, unrelated side effect: crossing the 7.5->7.7
  two-minor-release gap triggered `scripts/validate_pack.py`'s
  `last_reviewed_version is at least two feature releases behind` check for
  `agent-development-process`, `document-governance`, and
  `teach-while-building` (all last reviewed at `7.5.0`). Re-reading the
  versioning policy confirmed this session, "publicly-usable" is the
  operative qualifier for minor, and this skill stays `evolution-pack`
  (private) — no public capability actually changed, so **patch** is the
  correct classification. The staleness finding for the 3 unrelated skills
  is real and independent of this change; it is tracked as a separate
  follow-up (see Disclosed limitations), not folded into this release.
- `VERSION`, `README.md`, all 4 `plugin.json` files, `CHANGELOG.md`,
  `docs/history/RELEASES.md`, `docs/CLOUDBOX_SKILLS_CHANGE_HISTORY.md`,
  `CLOUDBOX_SKILLS_AGENT_HANDOFF.md` updated for the version bump (each was
  first written for `7.7.0` and then corrected to `7.6.29` in place, along
  with the reasoning above, rather than silently rewritten).
