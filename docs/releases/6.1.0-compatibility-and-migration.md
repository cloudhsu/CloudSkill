# CloudBox 6.1.0 compatibility and migration

- Existing imported Inbox candidates remain supported.
- Manual export/import advances to bundle format `2.0`.
- Unimported legacy/unknown bundles are `UNSUPPORTED`; no automatic migration,
  partial import, rewrite, or deletion occurs.
- Re-export from an upgraded machine when needed, or inspect and explicitly
  delete an unsupported archive.
- Git synchronization is an additional producer and grants no model, Skill
  edit, Git publication, or release authority.
- Rollback to 6.0 does not make format-2.0 bundles valid for its importer.
