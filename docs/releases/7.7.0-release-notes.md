# CloudBox Skills 7.7.0 release

Covers PRs #99–105 plus one directly-pushed hook-logging commit
(`36b611f`, CI-verified). Full detail in `CHANGELOG.md`'s 7.7.0 entry.

## Summary

- Unified hook logging: every wired hook now also appends its
  error/advisory message to one gitignored `.cloudskill-hooks-state/
  hooks.log`, purely additive (no exit-code/block-allow change).
- Windows-native PowerShell equivalents for the 3 hooks this repository
  wires directly into its own provider configs, closing the gap the
  bundled-hook manifest mechanism's earlier Windows work didn't reach.
  Skill context-budget gate raised to 20,000 bytes after a full
  41-Skill inventory.
- 9 real equipment-porting defects merged one-owner-each across 6
  public Skills (`framework-design`, `equipment-control-architecture`,
  `equipment-domain-modeling`, `codebase-architecture-discovery`,
  `code-review`, `safe-incremental-refactoring`) plus 2 private-tier
  Skills.
- New private-tier Skill `technical-case-content-generation`, closing
  the content-generation gap next to `game-marketing-and-monetization`,
  with a hard evidence-honesty constraint and mandatory hand-off for
  readiness sign-off.
- Routing-cue fix closing `cloudbox-skills` #15: `using-cloudbox-skills`
  now correctly routes checkpoint/roadmap tracking to
  `coding-agent-project-governance` instead of `document-governance`.

## Validation evidence

- `python3 scripts/run_all_checks.py`: PASS at the release tip.
- All 7 PRs (#99–105) individually CI-verified (GitHub Actions
  `Validate CloudSkill`) before merge; the one directly-pushed commit
  (`36b611f`) is also CI-verified on `main`.

## Limits

- `technical-case-content-generation` and its merged candidates are
  `private-operation` tier only -- not part of the public plugin bundle.
- The 9 equipment-porting cases and the routing-cue fix were verified
  via ad hoc `codex exec`/`claude -p` sampling (3 of 9, and 2/2
  respectively), not the formal rubric-graded pipeline.
- No hardware, device, platform-install, or production-deployment claims.
