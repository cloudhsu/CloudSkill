# CloudBox Skills 7.7.2 release

This patch release separates the public and private plugin package surfaces
when the private repository is used as a local marketplace.

## Summary

- `cloudbox-skills` now points to a generated core-only `public-plugin/`.
- `cloudbox-skills-private` remains backed by the private-only projection.
- Plugin, export, pack, and smoke validators verify physical package closure,
  not only the manifest Skill list.
- The disconnected-session Eval exporter is installed as a Skill-local
  `developing-eval/scripts/` executable on Codex and Claude-compatible
  projections.
- Standalone installer behavior and Skill IDs remain unchanged.
