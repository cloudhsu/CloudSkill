# CloudBox 6.1.0 pre-release evidence

Deterministic fixtures cover the shared architecture-question contract,
versioned bundle manifest and filename, manual export/import round trip,
private Exchange transport, unsupported archive isolation, Git source
idempotency, redaction, and no-change zero-model behavior.

Architecture model behavior execution remains `NOT RUN` until the bounded
release-significant gate is executed. Version synchronization, PR, merge, tag,
and Release are prohibited until that gate passes. Structural validation is
not model behavior PASS.

## First independent review RED

The first GPT reviewer found two high-severity defects and one compatibility
defect: the Actions adapter wrote Exchange state only to an ephemeral runner;
the importer accepted undeclared JSON members outside the manifest hash set;
and Python/schema host-agent normalization disagreed on underscores. The
candidate remained stopped. GREEN persists the private Exchange clone through
commit/push, requires the archive member set to equal the declared hash set,
and canonicalizes host/agent underscores to hyphens. Focused bundle, manual
exchange, source-sync, and redaction validators pass after correction. The
original reviewer output is retained privately under `.local/6.1-panel/` and
is not represented as a PASS verdict.

## Second independent review RED and correction

The second GPT reviewer verified all first-review repairs, then found two
remaining high-severity defects: the manual Exchange transport printed the
configured private remote, and an interruption after candidate/provenance
write but before checkpoint write minted a second candidate on retry. The
release remained stopped. The correction redacts success and failure output,
uses a stable operation identity derived from source, commit, and content,
repairs the same files on every retry, fingerprints scoped file content rather
than path inventory alone, and adds an interrupted-checkpoint regression. The
complete deterministic suite passed after correction. The reviewer output is
retained privately and is not converted into a PASS verdict.

## Final review correction and provider availability

The final GPT review found that cross-Skill relative references were not loaded
by Runtime Eval context assembly and that the disconnected exporter bundled
stale JSON files from prior outbox runs. The release remained stopped. Runtime
reference discovery now resolves declared Markdown references within the
canonical Skill root, including the shared architecture protocol, and a
regression proves the engine Skill loads it. A disconnected export now contains
only the candidate created by that invocation; a stale-outbox regression proves
the boundary. The full deterministic suite passes after both repairs.
