## RED/GREEN evidence

The isolated RED baseline removed the two proposed Skills while keeping the
router, cases, and supporting context otherwise equivalent:

- Routing: 18 records, overall pass `33.3333%`, primary accuracy `33.3333%`,
  execution-order accuracy `33.3333%`, forbidden-selection violation
  `11.1111%`; contract and context integrity stayed valid.
- Behavior: 12 deterministic records graded, 8 passed, average `76.4/100`,
  gate failed. One additional raw attempt ended in a Claude structured-output
  provider error and is retained as infrastructure evidence.

The candidate GREEN routing run passed all 18/18 records across three repeats:
contract validity, primary accuracy, required supporting recall, forbidden
selection, execution order, selected-set consistency, and context integrity
were all `100%`/zero violation as applicable.

The first full candidate behavior run completed all model calls for the
selected cases: 12 records were rubric-graded, 11 passed, average
`90.8/100`. It exposed one real content gap in `GARA-R03` (the asset handoff
did not always put measured size relationships, historical-versus-derived
status, and validation limits at row level). The Skill was corrected, then the
same target case plus adjacent `GARA-R01` was re-run three times each:

- Target and adjacent regression: 6/6 passed, average `93.9/100`, rubric gate
  passed.
- `LGPA-R01` and `LGPA-R03` remained passing in the full candidate behavior
  run; the legacy Skill was not changed by the art fix.

A later attempt to rerun the entire behavior suite after the fix was started
and preserved, but Claude returned HTTP 429 session-limit errors after the
first legacy case. It is not used as a false GREEN result; the release gate
uses the exact same-case post-fix run and adjacent regression above, plus the
already completed full candidate run.

## Release decision

Decision: **GO for 7.6.21, active/private only**.

This is not a stable/public promotion. The deterministic rubric measures
explicit engineering evidence coverage and does not prove complete semantic
correctness, visual quality, device compatibility, image upscaling quality,
or store/market performance. Those require real source/assets, target
viewport/device tests, and later human or cross-provider review.
