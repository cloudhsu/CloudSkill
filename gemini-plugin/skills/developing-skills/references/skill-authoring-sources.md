# Skill Authoring Sources and Adaptation

CloudSkill's skill-development method is informed by public skill-authoring work, including:

- `obra/superpowers`, especially its `writing-skills` and skill-testing guidance.
- The Agent Skills specification referenced by supported runtimes.
- CloudSkill's own architecture, documentation-governance, and evidence-discipline rules.

Adaptation rules:

- Use behavior-first evaluation without copying another repository's mandatory workflow wholesale.
- Preserve CloudSkill's role as a domain architecture and engineering-governance library.
- Keep process skills composable with external coding-agent methodologies.
- Cite external ideas; do not copy source text, examples, or implementation without license and attribution review.
- Treat external repository behavior as time-sensitive and re-check it before major future changes.
