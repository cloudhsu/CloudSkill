# Process Health Indicators

Use metrics diagnostically, not as performance theater.

Possible indicators:

- Lead time from accepted need to verified release.
- Batch size.
- Integration frequency.
- Escaped defect rate.
- Reopened defect rate.
- Requirement churn after baseline.
- Build and test reliability.
- Mean time to diagnose.
- Mean time to recover.
- Change failure rate.
- Unplanned work ratio.
- Review wait time.
- Percentage of requirements with acceptance evidence.
- Field issues by product/version.
- Aging of known risks and technical debt.

Avoid:

- Treating story points as productivity.
- Comparing teams using velocity.
- Counting documents without measuring decision or verification value.
- Rewarding defect closure without verifying recurrence prevention.
