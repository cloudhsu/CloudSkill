# Agent Lifecycle

## Discover

- Confirm valuable task.
- Define users and affected systems.
- Establish non-goals.
- Decide whether an agent is actually needed.
- Identify deterministic alternatives.

## Specify

- Task contract.
- Input/output schemas.
- Autonomy.
- Tools and data.
- Completion and escalation.
- Quality requirements.
- Risk controls.

## Evaluate First

- Golden cases.
- Negative cases.
- Failure injection.
- Authorization cases.
- Regression set.
- Metrics and thresholds.

## Architect

- Model/router.
- Instructions.
- Context/retrieval.
- Tool layer.
- State/memory.
- Orchestration.
- Validation.
- Tracing.
- Guardrails.
- Human approval.

## Implement

- Minimum vertical slice.
- Typed contracts.
- Deterministic validation.
- Safe tool adapters.
- Trace capture.
- Repeatable evaluation runner.

## Harden

- Security.
- Privacy.
- Reliability.
- Recovery.
- Cost.
- Latency.
- Versioning.
- Operational diagnostics.

## Release

- Reviewed specification.
- Passing critical gates.
- Known limitations.
- Monitoring.
- Rollback.
- Ownership.

## Improve

- Trace review.
- Feedback classification.
- Evaluation update.
- Controlled harness change.
- Regression.
- Versioned release.
