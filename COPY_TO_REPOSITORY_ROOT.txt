CloudSkill 5.6.0 Model Eval + Ollama direct-overwrite package

Copy the CONTENTS of this directory into the root of an existing CloudSkill 5.5.4 or 5.6.0 clone.
Preserve hidden directories such as .github, .codex-plugin, and .claude-plugin.
The package does not include .git and does not delete local configuration or Eval Inbox data.

After copying, run:
  python3 scripts/validate_runtime_evals.py
  python3 scripts/run_runtime_evals.py --provider ollama --model qwen3:4b --dry-run
  python3 scripts/run_all_checks.py
  git diff --check
